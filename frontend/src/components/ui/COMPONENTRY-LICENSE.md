# Componentry adaptations

Adapted from https://componentry.dev/r/magnetic-dock.json (retrieved 2026-09-27).
Documentation: https://componentry.dev/docs/components/magnetic-dock
Upstream: https://github.com/harshjdhv/componentry

Local adaptations: JavaScript, CSS theme tokens, router links, fixed hit targets,
transform-based magnification, persistent labels, keyboard navigation, and
touch/reduced-motion fallbacks. Uses the existing Framer Motion dependency.

DitheredLogo is adapted from https://componentry.dev/r/dithered-logo.json
(retrieved 2026-09-28). Documentation: https://componentry.dev/docs/components/dithered-logo.
It retains the upstream grayscale, diffusion, particle, and ripple algorithms,
with local Campusdesk artwork, JavaScript, a vector fallback, bounded pixel ratio,
and visibility/reduced-motion-aware rendering. The Campusdesk SVG is local project artwork.
